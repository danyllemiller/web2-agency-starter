# Web Design 2 · Agency Starter Files

Starter files for **Web Design 2** at Carson High School (Chapters 11–16).
Every lab on the class website (chswebdesignndevelopment.com) starts from a folder in this repo.

## Get the files (do this once)

**With Git (the agency way):**

```
cd ~/Desktop
git clone https://github.com/danyllemiller/web2-agency-starter.git
cd web2-agency-starter
```

When new files are added later in the year, get them with:

```
cd ~/Desktop/web2-agency-starter
git pull
```

**Without Git:** click the green **Code** button above → **Download ZIP** → unzip it on your Desktop.

> This repo is read-only for students. Don't push to it. For your milestones, copy a starter
> folder out to your Desktop and make **your own** repo on **your own** GitHub account.

### Chapter 11 notes
- `day1-portfolio-repo/`: copy it to your Desktop and rename it `portfolio-repo` (Milestones 1–3).
- `day2-conflict-lab.zip`: **unzip it on your Desktop.** It's a ready-made Git repo with two branches that clash. It's zipped so its own Git history stays inside it.
- `day4-link-hunt/`: the Linux Link Hunt.
- `day5-readme/`: the README for Milestone 4.

### Chapter 12 note
WordPress runs in **LocalWP** (https://localwp.com). If LocalWP can't be installed on your laptop,
use **WordPress Playground** in the browser instead: https://playground.wordpress.net
(no install; export your site before you close the tab).
